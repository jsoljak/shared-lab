# Ke stažení

Tady je všechno, co si můžeš stáhnout. **Každá věc je jeden soubor a obsahuje všechno, co potřebuje.** Nestahuj nic jiného z tohoto repa, ostatní složky slouží ke čtení.

Klikni na název **pravým tlačítkem myši** a zvol **Uložit odkaz jako…**, nebo na něj klikni levým: soubor se stáhne.

| Soubor | Co to je | Jak ho použít |
|---|---|---|
| [prompt-coach.skill](prompt-coach.skill?raw=true) | Skill: mentor, který tě naučí psát lepší prompty. | Otevři ho v aplikaci Claude a ulož jako skill. [Návod](../skills/prompt-coach/README.md) |
| [moto-buy-advisor.skill](moto-buy-advisor.skill?raw=true) | Skill: poradce při nákupu nové nebo ojeté motorky. | Otevři ho v aplikaci Claude a ulož jako skill. |
| [jak-z-ai-dostat-uzitecnou-odpoved.zip](jak-z-ai-dostat-uzitecnou-odpoved.zip?raw=true) | Návod: jak zadávat AI dotazy, aby odpovědi dávaly smysl. | Rozbal (pravé tlačítko, **Extrahovat vše**) a otevři textový soubor. |
| [OPRAVA__zaklad-v0-2-0-na-v0-3-0__2026-09-24.zip](OPRAVA__zaklad-v0-2-0-na-v0-3-0__2026-09-24.zip?raw=true) | Oprava: uklidí složku Claude podle nové struktury (Windows 10). | Rozbal a dej soubor Claudovi. [Návod](../tools/folder-restructure/README.md) |

Soubor `.skill` je zabalený balík, uvnitř má celý skill včetně podkladů. Kdyby ho aplikace nechtěla otevřít, přejmenuj příponu `.skill` na `.zip`.
