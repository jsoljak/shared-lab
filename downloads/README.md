# Ke stažení

Tady je všechno, co si můžeš stáhnout. **Každá věc je jeden soubor a obsahuje všechno, co potřebuje.** Nestahuj nic jiného z tohoto repa, ostatní složky slouží ke čtení.

Klikni na název **pravým tlačítkem myši** a zvol **Uložit odkaz jako…**. Balíky `.skill` se stáhnou i obyčejným kliknutím. Textový soubor `.md` se při kliknutí otevře jako text, proto ho ukládej pravým tlačítkem (nebo v otevřeném textu zmáčkni **Ctrl + S**).
