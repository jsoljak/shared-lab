# Michigan Closed-Season Regulations

Michigan is the one state in this toolkit's scope with real closed seasons for
walleye, northern pike, and muskellunge (see `SKILL.md` rule 4). This isn't in the
access-point FeatureServer (`fetch_michigan.py`) — it's regulation text, tracked
here separately and re-verified each season, since exact open dates move slightly
year to year (last Saturday of April / first Saturday of June, not a fixed date).

**Confirm the current year's exact date against Michigan DNR before stating it as
fact** — this file gives the pattern, not a guarantee of this year's specific date.

## Walleye and Northern Pike (inland waters)

- **Lower Peninsula:** possession season opens the **last Saturday of April**.
- **Upper Peninsula:** possession season opens **May 15**.
- Catch-and-immediate-release is generally allowed year-round outside the
  possession window — confirm this isn't water-specific before relying on it.

## Muskellunge (inland waters)

- Possession season opens the **first Saturday of June**, statewide.
- Same catch-and-release note as above applies.

## Source

Michigan DNR season announcements (e.g., the annual "Trout, Walleye and Pike Seasons
Open" press release published each spring at michigan.gov/dnr/about/newsroom). Check
the current year's release before fishing — this file is a pattern reference, not a
live feed.
